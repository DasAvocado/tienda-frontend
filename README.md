Aplicación web desarrollada en Angular que actúa como la interfaz de usuario del sistema Paupérrimos. Se integra con Microsoft Azure AD (Entra ID) para la gestión centralizada de identidades mediante el flujo OAuth 2.0 / OIDC con PKCE y consume microservicios protegidos a través de AWS API Gateway.  🛠️ Tecnologías UtilizadasFramework: Angular  Autenticación: MSAL Angular (@azure/msal-angular, @azure/msal-browser)  Servidor / Contenedor: Nginx en Docker  Integración Cloud: AWS API Gateway / Azure AD IDaaS  📋 Requisitos PreviosNode.js: v18.x o superiornpm: v9.x o superiorAngular CLI: v17.x o v18.x
